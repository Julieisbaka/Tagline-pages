Appearance settings

Choose the language, built-in light or dark themes, fonts, and editor preferences in Settings > Appearance. Tagline includes high-contrast themes and respects reduced-motion preferences. Optional custom CSS is available from appearance settings.

Create a theme

Themes are JSON color palettes with optional CSS custom-property overrides. Start with a built-in theme, choose Customize current theme, and adjust the palette. Export the result as JSON to keep or share it; import a JSON theme to apply it.

Tagline validates imported themes and displays import errors instead of partially applying invalid files. The repository’s theme guide lists the supported colors, variables, metadata, limits, and JSON schema.

Install an extension

  1. Open Settings > Extensions > Open extensions folder.
  2. Add an extension folder with a manifest.json and its referenced files.
  3. Choose Reload extensions, review the requested permissions, then enable the extension.

Extensions can contribute commands, ribbon shortcuts, settings, themes, sidebar panels, and dialogs. Entry scripts run in a sandboxed worker through the supplied Tagline API; they do not have access to the app’s DOM or Node.js. Review permissions and extension code before enabling an extension.

Schemas and examples

The repository includes JSON Schemas for speech flows, themes, extension manifests, and exported extension settings. Canvases follow the standard JSON Canvas format. Use the schemas to validate your files or enable editor completion, and see the demo extension for a working example.
